My dream spare-time project has been to use the @BKLYNlibrary digitized collections to dive deep into the geospatial history of brewing in Brooklyn over the last 160 years or so

In fact! Totally forgot that that I did this related project a few years ago when I was testing a ton of OCR systems, searchable PDFs and OCR coordinate text for amazing Brewery Directories from 1896 - 1918: https://github.com/hadro/brewery-guides/ [Note: that repo has since been updated because I returned to the project after a decade (thanks, Claude Code!; see this post for more: TKTK), but you can [still see the repo as it looked when I published these Tweets in 2020](https://github.com/hadro/brewery-guides/tree/af82b9c6f167622e741c095b6cec940fbc6d4eeb) thanks to the git history]

Logical next step would be to parse out the BK breweries in those guides and see if I could connect them to @Brooklynology digital photos or maps... hm, I fear this may be a weekend project coming on.

All using #IIIF and annotations, of course :)
